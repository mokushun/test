# 都道府県ボードゲーム（todofuken-board）

小学生向けの、道路ネットワークを使った都道府県の取り合いゲームです。最大3人（人間1人＋CPU）で遊びます。

## 開き方
- `index.html` をブラウザで開くだけで動きます（外部ライブラリ不要）。カードデータ `prefecture-cards.js` を同じフォルダに置くと、カード表示とクイズが有効になります。無い場合は内蔵の豆知識表示で動作します。
- GitHub Pages でも公開できます。

## 現在のルール
- 2人プレイは北海道・沖縄から固定スタート。3人プレイは北海道・沖縄・静岡から固定スタート。
- 手番順はゲーム開始時にランダムで決まります。
- 各プレイヤーはサイコロを振り、出た目の数だけ道路に沿って移動します。分かれ道では進む先を選び、原則として直前の県へ戻る道は選びません（行き止まりでは戻ります）。サイコロの残りマス数を表示し、必ず出目の数だけ移動します。
- **獲得・対決が起きるのは、移動終了時に到着した都道府県だけです。通過した県では何も起きません。**
- 誰も所有していない県に到着すると、そのプレイヤーが県とカードを獲得します。
- 他のプレイヤーが所有する県に到着すると対決します。挑戦者と所有者がそれぞれサイコロを振り、所有者には防衛ボーナス＋1。合計が高い方が勝ち、同点は所有者の勝ちです。勝者が県とカードを所有します。
- 自分の所有県に到着しても、追加の処理はありません。
- 同じ地方の県を3つ以上所有すると、その地方ごとに＋3点。所有が2県以下になるとボーナスを失います。
- 各プレイヤーが12回ずつ手番を行ったら終了。全47都道府県が所有されていなくても終了します。

## 得点
- 所有する都道府県1県につき1点。
- 3県以上所有する地方1つにつき3点。
- 合計点が最も高いプレイヤーが勝ちます。

- 東北：青森・岩手・宮城・秋田・山形・福島
- 関東：茨城・栃木・群馬・埼玉・千葉・東京・神奈川
- 中部：新潟・富山・石川・福井・山梨・長野・岐阜・静岡・愛知
- 近畿：三重・滋賀・京都・大阪・兵庫・奈良・和歌山
- 中国：鳥取・島根・岡山・広島・山口
- 四国：徳島・香川・愛媛・高知
- 九州・沖縄：福岡・佐賀・長崎・熊本・大分・宮崎・鹿児島・沖縄

## 画面
- 日本地図は2040×2040pxの拡大表示で、枠内をスクロールできます。手番の開始時と移動のたびに、今動いているプレイヤーのいる県が中心に来るよう自動スクロールします。
- 分かれ道では、行き先の候補の県が地図上で大きく赤ピンクに光り、輪が広がるアニメーションで示されます。その県のピンをタップして進む先を選べます（従来のボタンでも選べます）。
- 他プレイヤーの県への対決では、あなたが挑戦する側・防衛する側のどちらでも、あなたのサイコロは自動では振られず、タップして自分で振ります。対決の開始と勝敗は画面中央に大きく表示されます（CPU同士の対決は従来どおり自動です）。
- 所有県の県域は、所有プレイヤーの色で塗り分けられます。
- 県をクリックすると、県庁所在地・特産品・所有者・道路接続を確認できます。
- 「あなたの都道府県カード」には、自分が現在所有している県のトレーディングカード風カードが並びます。表面は地方色の枠・大きな絵文字・県名と番号・県庁所在地・特産品・豆知識、タップすると裏返って裏面の三択クイズで答え合わせができます。県を獲得・奪取したときは、そのカードがポップアップで表示されます。県をクリックしたときの詳細にも、カード情報とクイズ（答えは折りたたみ）が表示されます。
