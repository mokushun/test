# 都道府県ボードゲーム（todofuken-board）

桃太郎電鉄風のすごろく型ボードゲームの試作。地理の学習が目的で、47都道府県・県庁所在地・特産品を、物件購入と投資の仕組みで覚える。

## 開き方
- `index.html` をブラウザで開くだけで動く（1ファイル完結、外部読み込みなし、端末標準フォント使用）。
- GitHub Pages で公開する場合は、このフォルダの中身をリポジトリに置いて Pages を有効化する。サーバー（Node.js / nginx）は不要。

## 遊び方
- プレイヤーは あなた（赤）＋ CPU 3人（さくら＝青、たけし＝緑、ゆき＝オレンジ）。期間は1年（12ラウンド）／2年（24ラウンド）。
- 自分の番では、地図の海上ウインドウにあるサイコロ自体をタップするとサイコロが回る（「サイコロをふる」ボタンはない）。
- 止まった県の特産品物件を買える。購入時は県庁所在地クイズ（正解で2割引）。他人の県に止まると賃料を払う。自分の県では物件をレベルアップできる（屋台→店舗→工場）。
- 同じ地方の物件を揃えると収益2倍（地方独占）。目的地の県に最初に着くとボーナス。目的地では特産品クイズ（正解で+150万円）。
- 一周ごとに決算（物件収益）。期間終了時に、現金＋物件価値の総資産で順位が決まる。

## 地図
- 中央の日本地図は、実際の県境データ（47都道府県のポリゴンを簡略化して約18KB、ファイル内に埋め込み）で描いている。県庁所在地の位置に★印。
- 取得した県は、所有プレイヤーのカラーで塗られる。プレイヤー情報とサイコロは、地図の海上（日本海側・太平洋側）に浮かぶウインドウに配置。
