# 他AIへの作業依頼：47都道府県カードの内容制作

## 目的
「にほん全国たんけん！」で、都道府県を獲得したときに手に入るカードを、子ども（小学校5年生）が読んで楽しみながら地理を覚えられる内容にする。

## 今回の依頼範囲
- 47都道府県すべてのカードデータを作る。
- **今回はゲーム本体 `index.html` を編集しない。**
- 既存のゲームルール、道路データ、地図、得点計算、所有権の処理を変更しない。
- 成果物は `game/todofuken-board/prefecture-cards.js` のみとする。

## データ形式
次の形式で、JIS都道府県順に47件を作成する。

```js
window.PREFECTURE_CARD_DATA = [
  {
    name: "北海道",
    title: "でっかい大地と乳製品",
    emoji: "🥛",
    specialty: "乳製品",
    fact: "小学生にも伝わる短い豆知識（およそ35〜65文字）",
    question: "この県・地域に関する三択クイズ",
    choices: ["選択肢A", "選択肢B", "選択肢C"],
    answer: "正解と同じ文字列",
    explanation: "正解の理由や覚え方を一文で説明"
  }
];
```

## 内容の基準
- 都道府県名は47件すべて正確にし、重複・欠落を作らない。
- 県庁所在地、特産品、地理・歴史・文化・自然のいずれかを扱う。
- 既存 `PREFS` データの特産品・県庁所在地・豆知識を出発点にしてよいが、丸写しではなく子ども向けに読みやすくする。
- クイズは各県1問、三択。選択肢は同じ種類・同じ粒度にそろえ、正解は必ず choices の中に1つだけ含める。
- 不確かな生産量順位・日本一などは避けるか、信頼できる根拠を確認する。誇張や古い統計を断定しない。
- 表現は小学校5年生が一読で理解できる言葉にする。漢字には必要に応じてふりがなを付けてもよい。
- 文章は短く。fact は35〜65文字程度、explanation は一文。
- 絵文字はカードの目印として1つ。外部画像や画像URLは使わず、ファイルを軽量に保つ。
- カードの文章・クイズは、県の所有権やゲーム得点には影響させない。

## 検収条件
1. 47件であること。
2. 都道府県名がJIS順で、現在の `PREFS` の順序と一致すること。
3. 各件に title / emoji / specialty / fact / question / choices / answer / explanation があること。
4. choices が3件で、answer がその中にちょうど1回含まれること。
5. JavaScript構文が正しいこと。
6. 既存 `index.html` は変更していないこと。
